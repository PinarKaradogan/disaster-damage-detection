# Dataset

The xBD / xView2 dataset is stored locally. The dataset itself and everything under
`data/processed/` are not committed to GitHub; only this README is tracked.

## Layout

```
data/
├── train/
│   ├── images/
│   ├── labels/
│   └── targets/
├── test/
│   ├── images/
│   ├── labels/
│   └── targets/
├── processed/
└── README.md
```

- `data/train/{images,labels,targets}`: xBD Challenge Training Set
  (2,799 pre/post image pairs).
  - Source archive: `train_images_labels_targets.tar.gz`
  - SHA1: `b37a4ef4ee9c909e2b19d046e49d42ee3965714b`
- `data/test/{images,labels,targets}`: reserved for the Challenge Test Set; to be added later.
- `data/processed/`: intermediate files generated by notebooks and scripts,
  e.g. `buildings.csv`.
